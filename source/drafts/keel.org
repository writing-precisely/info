

* About


Keel is the first implementation of the [[file:simple-data-storage-model.org][simple data storage model]].
It must be both practical and illustrative.

Supported layers: 1 and 2.

Symbols (N, V, T, $, [ ]) are used as in the model.

* Separators
- primary ($) :: end of line
- secondary (T) :: =|=
- third level :: =/= (see Slash)

* Padding
Whitespace around names, values and separators is padding. It belongs
to reading mode and may be removed or treated differently in writing or
storage mode.

A blank line is not padding at layer 2: it is a run of primary
separators and closes all open sequences.

* Modes
- reading, writing, storage :: conversion between modes is lossless at
  the data level. A mode may change spelling (e.g. expand =/=) but never
  the records.

* Layer 1
#+begin_example
user  | That's it
agent | Would you like an extra side of guacamole?
user  | Yes
steps |
      | confirms the cart contents
      | provides the total and pickup time
      | asks for payment confirmation
      |
#+end_example

* Layer 2
** Double bar
=N || V= is =NTTV$=: a sequence start and its first item on one line.
#+begin_example
turns || one
      | two
      |
#+end_example

** Slash
=/= is Keel's third-level separator. It replaces =T$= and needs a name
on both sides.

- =a / b | v= :: =a |= followed by =b | v=
- =a / b / c |= :: three nested sequence starts
- trailing =/= :: may replace the final =T$= if the record already
  contains a =/=: =a / b /= is =a / b |=
- names :: =/= cannot appear in a name. Every =/= before the first =|=
  is a separator; every =/= after it belongs to the value
  (=url | http://a/b= is safe).
- each =/= opens a sequence and needs its own close (or a blank line).

Undefined:
- a record ending with =/= that contains no earlier =/= (=a /=)
- a record ending with a name after =/= (=a / b=)
- a leading =/= (=/ a |=)

** Example
#+begin_example
update / implementation /
task       | combine confirmations
when user  | proceeds to checkout
then agent || gives summary, total and pickup time
           | asks for one confirmation
           |

#+end_example
