    Writing Precisely#

    Precise writing is a discipline of constructing text by applying three fundamental intentions (the order matters):

    1. Complete: The text must include all possible details about the subject.

    2. Relevant: The complete text must only include the details which belong to the current task.

    3. Concise: The relevant text must only include the details which belong to the current context.

    This discipline realizes these intentions via its own methods and tools.

    The goal of Precise writing is to produce text as a system of interrelated terms.

    Featured Perspectives#

    [Foundation] Human-AI Interface

    human-AI interaction needs another basis, such that control is distributed between us and artificial intelligence. If what we control is the product that we are shaping, then the requirement to use well defined language will focus on the product and apply to all controlling agents, human or artificially intelligent.

    [Foundation] Target Audience

    Regardless of who the readers are, the author can view the target audience as a collection of concepts from the text. Specifically, the target audience comprises all concepts that need not be explained because the reader must know these concepts already in order to be able to understand what the author is telling them.

    [Foundation] Closed Term System

    Within a closed term system, communication is happening on another level: AI does not have to wait for a human to provide details of the system. After a human introduces the idea and formulates the problem or the desired state, whatever the closed term system is designed to be initialized with, a human interacts with AI via the formal texts that define the system. This effectively makes it an interface between a human and AI.
